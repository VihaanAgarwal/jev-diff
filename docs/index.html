About this report

This file contains saved question definitions, answers, model IDs, state digests, and policies. There are no network requests or external assets. Raw state is omitted; question text and labels can still be sensitive. A state digest is not anonymization.

Gate equality is on the upper side (value ≥ threshold). Choice and Score confidence is the API's confidence field, not the highest probability. Probability bars show recorded values; distribution distance uses normalized values. This report is a fixed snapshot. It does not replay your application or call Jev.
